# V1 acceptance

## Current release candidate — 2026-11-11

The current source and generated files are the release authority. `artifacts/model_metadata.json`, `artifacts/eval.json`, `artifacts/calibration.json`, and `public/demo-fallback.json` are regenerated by `make train` and the fallback export step; the performance page reads the generated evaluation rather than relying on the historical V1 figures below.

- Active model: Cox PH, version `cox-ph-v7-seed-20261110-asof-2026-11-11`; validation IPCW integrated Brier: Cox 0.0508, Kaplan–Meier 0.0757, LightGBM 0.0840.
- Held-out model comparison is separate from selection. The selected model's candidate test IPCW integrated Brier is 0.0618. The complete deployed Cox scoring path (conditional survival, client-history tail blend, validation-fitted 14-day calibration, and overdue recovery ceiling) was replayed on 377 eligible synthetic observations: paid-only median absolute P50 date error 12 days over 330 paid outcomes; Brier 0.0857 / 0.2795 / 0.6578 at 14 / 30 / 60 days, with 241 / 128 / 34 observations. Later horizons have small samples and censoring limits interpretation.
- Drift backtest from the generated artifact: 9 clients flagged, 5 generator-defined positives (55.6% precision; 33.3% recall) in a 90-day synthetic evaluation. This is not a real-world alert guarantee.
- The static fallback snapshot is generated from the seeded data and checked for open invoice count/amount reconciliation, including disputed and unforecastable balances.
- Current `make check`: Ruff passed, 86 tests passed, ESLint passed, TypeScript passed, and the Next.js production build passed. Two upstream Starlette/AnyIO deprecation warnings remain.
- Render deployed API and web at `8bf6675`; live portfolio, queue, brief, stories, evaluation, web proxy, tour, performance page, and packaged fallback were checked. Live AI status is `configured: true` for Google Gemini `gemini-3.5-flash-lite`. An isolated synthetic run returned a grounded Gemini invoice draft with persisted model provenance and a Gemini-classified reply preview awaiting approval. See `docs/execution-status.md`.

## Original V1 verification — historical, 2026-11-10

## Run locally

Requirements: Bun 1.3.6, Python 3.12/3.13 with `uv`, and Docker Compose.

```sh
make setup
# Set OPERATOR_USERNAME, OPERATOR_PASSWORD, and SESSION_SECRET in .env.
make dev
```

- Dashboard: `http://localhost:3000`
- API docs: `http://localhost:8000/docs`
- Readiness: `http://localhost:8000/ready`
- Reset the synthetic fixture set: `make seed-demo`
- Retrain and evaluate: `make train`
- Run local checks: `make check`
- Read execution/setup checklist: `docs/execution-status.md` and `docs/external-setup.md`
